# Net-Async-Keycloak

Async Perl client for [Keycloak](https://www.keycloak.org/) identity management
(IO::Async + Future): OIDC plus the Admin REST API. The async twin of `WWW::Keycloak`,
modelled on [Net::Async::Zitadel](https://metacpan.org/pod/Net::Async::Zitadel).

**Status: skeleton.** Nothing is implemented yet.
